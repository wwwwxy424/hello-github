# hello-github

我的作业仓库：C 语言课堂作业 + C++ 练习。

## 目录约定

| 目录 | 内容 | 用什么写 |
|---|---|---|
| `c/` | C 语言课堂作业 | Visual Studio / CodeBlocks |
| `cpp/` | C++ 练习 | 小熊猫 C++ |

每个作业一个子文件夹，例如 `cpp/01-输入输出/`、`c/实验二-循环/`。

编译产物（`.exe`、`.o`、`.obj`、`.vs/`、`build/` 等）已经在 `.gitignore` 里排除，不会被提交上去。

## 提交步骤

1. 代码写在本文件夹里（小熊猫新建项目时把位置选到 `cpp/` 下面）
2. 打开 GitHub Desktop，左侧切换到这个仓库
3. 左下角写一句说明（例如"完成循环作业"）→ 点 `Commit to main`
4. 右上角点 `Push origin` 上传到 GitHub

## 环境

- IDE：小熊猫 C++ 3.4（自带 MinGW-w64 GCC）
- 版本控制：GitHub Desktop 3.6.7
